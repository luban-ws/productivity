# JSDoc 模板系统工作原理

本文档解释 `jsdoc-template` 目录中的模板系统是如何工作的。

> **注意**: 关于为什么 `jsdoc-template` 在 `src/` 外面，请参考 [ARCHITECTURE.md](../ARCHITECTURE.md)

## 概述

JSDoc 模板系统是一个基于模板的文档生成器，它将解析后的代码注释（doclets）转换为 HTML 文档。

## 核心组件

### 1. `publish.js` - 模板发布器

这是模板系统的入口点，JSDoc 会调用 `exports.publish()` 函数。

**主要功能**：

- 接收解析后的文档数据（TaffyDB 格式）
- 设置模板引擎和视图
- 处理文档数据（排序、链接、签名等）
- 生成 HTML 文件

**关键流程**：

```javascript
exports.publish = function (taffyData, opts, tutorials) {
    // 1. 初始化数据
    data = taffyData;

    // 2. 创建模板视图
    view = new template.Template(templatePath + "/tmpl");

    // 3. 处理数据
    data = helper.prune(data);
    data.sort("longname, version, since");

    // 4. 生成 HTML 文件
    generate("Index", packages, indexUrl);
    generate("Class: " + className, classes, url);
    // ...
};
```

### 2. 模板文件（`.tmpl` 文件）

位于 `tmpl/` 目录，使用 **Underscore Template** 语法。

**模板语法**：

- `<?js= variable ?>` - 输出变量值
- `<?js if (condition) { ?> ... <?js } ?>` - 条件语句
- `<?js= this.partial('template.tmpl', data) ?>` - 包含子模板

**主要模板文件**：

| 模板文件          | 用途                               |
| ----------------- | ---------------------------------- |
| `layout.tmpl`     | 页面布局（HTML 结构、导航、页脚）  |
| `container.tmpl`  | 内容容器模板                       |
| `method.tmpl`     | 方法/函数文档模板                  |
| `params.tmpl`     | 参数列表模板                       |
| `returns.tmpl`    | 返回值模板                         |
| `details.tmpl`    | 详细信息模板（版本、作者、继承等） |
| `aliases.tmpl`    | 别名列表模板                       |
| `examples.tmpl`   | 示例代码模板                       |
| `properties.tmpl` | 属性列表模板                       |
| `members.tmpl`    | 成员列表模板                       |

### 3. 静态资源（`static/` 目录）

包含 CSS 样式和 JavaScript 文件：

- `styles/` - CSS 样式表
- `scripts/` - JavaScript 文件（代码高亮、行号等）

## 工作流程

### 步骤 1: JSDoc 解析代码

JSDoc 解析源代码，提取注释和类型信息，生成 **doclets**（文档对象）。

### 步骤 2: 数据存储（TaffyDB）

所有 doclets 存储在 **TaffyDB** 数据库中，这是一个内存数据库，支持查询和过滤：

```javascript
// 查询所有类
var classes = data({ kind: "class" });

// 查询特定名称
var myClass = data({ longname: "MyClass" });
```

### 步骤 3: 数据预处理

`publish.js` 对数据进行预处理：

1. **数据清理** (`helper.prune`) - 移除不需要的 doclets
2. **排序** (`data.sort`) - 按名称、版本、日期排序
3. **添加签名** (`addSignatureParams`, `addSignatureReturns`) - 生成函数签名
4. **创建链接** (`helper.registerLink`) - 建立文档间的链接关系
5. **处理别名** - 为有 `@aliases` 标签的 doclet 创建别名文档

### 步骤 4: 模板渲染

使用 Underscore Template 引擎渲染模板：

```javascript
// 渲染模板
var html = view.render('container.tmpl', {
    title: 'Class: MyClass',
    docs: [doclet1, doclet2, ...]
});

// 解析链接
html = helper.resolveLinks(html);

// 写入文件
fs.writeFileSync(outputPath, html, 'utf8');
```

### 步骤 5: 生成 HTML 文件

为每个文档实体生成对应的 HTML 文件：

- `index.html` - 索引页
- `MyClass.html` - 类文档
- `global.html` - 全局函数/变量
- `source-*.html` - 源代码文件

## 模板系统特性

### 1. 支持自定义标签

模板系统支持通过插件添加自定义标签（如 `@aliases` 和 `@category`）：

```javascript
// 在 jsdoc-aliases.js 中定义
exports.defineTags = function (dict) {
    dict.defineTag("aliases", {
        onTagged: function (doclet, tag) {
            doclet.aliases = tag.text.split(",");
        },
    });
};
```

### 2. 分类支持

模板支持按 `@category` 标签对方法进行分类显示：

```javascript
// 在 publish.js 中
members.categories = data("method")
    .get()
    .reduce(function (cats, method) {
        var cat = method.category || "Other";
        if (cats[method.memberof].indexOf(cat) === -1) {
            cats[method.memberof].push(cat);
        }
        return cats;
    }, {});
```

### 3. 别名支持

为有 `@aliases` 标签的 doclet 创建别名文档：

```javascript
// 在 jsdoc-aliases.js 中
exports.handlers = {
    parseComplete: function (e) {
        doclets.forEach(function (doclet) {
            if (doclet.aliases) {
                doclet.aliases.forEach(function (alias) {
                    e.doclets.push(createAlias(doclet, alias));
                });
            }
        });
    },
};
```

## 模板示例

### `layout.tmpl` - 页面布局

```html
<!DOCTYPE html>
<html>
    <head>
        <title>JSDoc: <?js= title ?></title>
        <link rel="stylesheet" href="styles/jsdoc-default.css" />
    </head>
    <body>
        <div id="main">
            <h1><?js= title ?></h1>
            <?js= content ?>
        </div>
        <nav><?js= this.nav ?></nav>
        <footer>Generated by JSDoc</footer>
    </body>
</html>
```

### `method.tmpl` - 方法模板

```html
<dt>
    <h4 id="<?js= id ?>"><?js= name ?><?js= data.signature ?></h4>
</dt>
<dd>
    <?js if (data.description) { ?>
    <div class="description"><?js= data.description ?></div>
    <?js } ?> <?js if (data.params && params.length) { ?>
    <h5>Parameters:</h5>
    <?js= this.partial('params.tmpl', params) ?> <?js } ?> <?js if (data.returns && returns.length)
    { ?>
    <h5>Returns:</h5>
    <?js= this.partial('returns.tmpl', returns) ?> <?js } ?>
</dd>
```

## 自定义模板

### 修改现有模板

1. 复制 `jsdoc-template/` 目录到你的项目
2. 修改 `.tmpl` 文件
3. 在配置中指定模板路径：

```json
{
    "jsdoc": {
        "opts": {
            "template": "./my-custom-template"
        }
    }
}
```

### 添加新模板

1. 在 `tmpl/` 目录创建新的 `.tmpl` 文件
2. 在 `publish.js` 中使用 `this.partial()` 引用：

```javascript
<?js= this.partial('my-custom.tmpl', data) ?>
```

## 依赖库

- **TaffyDB**: 内存数据库，用于存储和查询 doclets
- **Underscore Template**: 模板引擎，用于渲染 HTML
- **JSDoc Helper**: JSDoc 提供的工具函数（链接、格式化等）
